# Pete's of Mind

Website for **Pete's of Mind**, a house sitting service: plant watering, pet care, and general home check-ins for people who are away.

## Site

The site is a single static page, `index.html`, with no build step. It's meant to be hosted with GitHub Pages:

1. In the repository, go to **Settings → Pages**.
2. Under **Build and deployment**, set **Source** to *Deploy from a branch*.
3. Choose the `main` branch and the `/ (root)` folder, then save.

The site will be published at `https://jthughey.github.io/petes-of-mind/`.

## Before going live

Replace the placeholder contact details in the **Contact** section of `index.html` (search for `TODO`):

- the phone number (`tel:` link and the visible text)
- the email address (`mailto:` link and the visible text)
